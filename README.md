# Homebrew tap for Anser

[Anser](https://nevin.github.io/anser/) is a macOS terminal with a real command editor, built on Ghostty.

```bash
brew install --cask nevin/tap/anser
```

Anser updates itself, so there's no need for `brew upgrade`. To remove it along with its settings and history, run `brew uninstall --zap anser`.

The cask is updated automatically with each [release](https://github.com/nevin/anser/releases).
